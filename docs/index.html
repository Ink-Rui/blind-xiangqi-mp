怎么玩

  1. 棋子暗置开局除将帅外全部背面朝上，按所选模式随机摆放。
  2. 按位置走棋暗子按它所在位置的「位置型棋种」走法移动，走完那一步才翻开。
  3. 操作权己方半盘的暗子、己方颜色的明子，轮到你时都能操作。
  4. 吃错代价暗子归属未知，谁都可以吃；误吃己方将帅按吃将判负，双人同屏可协商悔一步。
  5. 胜负吃掉对方将帅立即获胜；将军规则下被将死或无子可动同样落败。
  6. 和棋120 个半回合无吃子，或三次重复局面，判和。

同一份规则引擎（core/engine.ts）同时驱动小程序与网页版，开源在 GitHub。
